# 中文战斗状态显示

本轮把战斗地图悬浮信息和遭遇列表中的动态状态说明接到语言资源：原生效果名称与简要机制、持续时间、豁免难度、施加者、法术来源，以及专注、力竭、濒死、伤势稳定、非致命击昏、再生和沉默区域。没有修改条件机制、持续时间计数、保存的原名或英文模型工具说明。

## 数据与名字边界

ConditionPresentation 是可选、与语言无关的公共显示数据。生产者从现有规则元数据提取回合开始／结束、当前／下个回合、剩余轮数、豁免与来源；界面通过 locale 和消息模板渲染。既有 label、rounds、note 保留原输出，旧消费者继续可用。

公开名字只从当前查看者能见到的战斗单位中解析。新增数据不发送原始来源 ID 或隐藏单位名；敌人类型名使用目录译名，角色和自定义专名保留原样。例如敌人来源为“哥布林 2”，玩家即使取名 Goblin 也保留该名字。准备动作的自定义触发文本、未知法术／状态和第三方包文本不做词语替换。

短持续时间显示轮数，长持续时间沿用现有规则说明的换算与取整方式，如 4800 轮显示 8 小时；计数和到期机制没有变化。回合元数据优先于附带轮数，中文界面不再同时显示两个相冲突的持续方式。力竭说明沿用源文累计效果，不自行增加源文未写的死亡结论；再生、非致命击昏和伤势稳定继续区分。

## 内置资料与资源加载

逐项对照 274 个原生效果的英文名称、全部别名及简要说明，形成 548 个双语资料键；另有 64 个显示模板、参数和核心状态名称键。译文保持骰子、数值、单位、触发时机、限制与伤害类型；只去掉玩家不需要的内部工具调用指令。术语沿用既有法术名和“黯蚀”等规则译法。审校属于实施代理的源文比对，没有独立人工审校。

源文和目录指纹见 [condition-material-translations.json](condition-material-translations.json)，由 lint 与回归检查校验。Suggested 保留语境区别：状态为“受到暗示”，法术选择建议为“推荐”。所有既有英文／中文资源键值保持不变，612 个新键只进入 combatDetail 内容资源，根页面 UI 资源没有增长。浏览器只导入目录别名索引和格式化器，不导入规则注册表、数据库或完整翻译源目录。
