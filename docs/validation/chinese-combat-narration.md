# 中文战斗结论与叙事验收

本次交付将关键战斗结论从 AI 自由叙事中分离。命中、伤害、倒地、死亡、治疗、已确认的法术位与资源使用按实际工具结果渲染；AI 描写动作、环境和对白。英文也使用同一事件结构和英文渲染器，历史消息保持原文。

## 实现与接口

- `CombatFact` 保存工具交换序号、结果路径、独立事件 ID、已知的行动者/目标 ID 与名称。每次调用及多重攻击的每次挥击独立保存，不合并成单个怪物命中标记。缺少明确数值时不捏造数据。
- `COMBAT_PRESENTATIONS: Record<AppLocale, ...>` 强制每个注册语言实现渲染器。名称别名用于显示，规则、工具参数与 ID 保持原协议。新工具结果形状通过事实采集适配扩展，不依赖输出语言。
- 显式 `hit=false`、命中但零伤害、`knockedOut/down/dropped`、`dead/slain` 分开呈现。法术位消耗读取服务器确认的 `slot/slotSpent`，不依据模型请求的环数推测；预览、免费施法不生成虚假的消耗。反制后的真实消耗仍可呈现。
- 术语修复后，施法效果工具确认成功使用“施放了”，仅施法资源处理使用“效果尚待确认”；明确击昏才写“失去意识”。治疗用“获得 N 点治疗”，不等同于生命值净增量。详见[术语与名称修复](chinese-terminology-repairs.md)。
- 引擎结论在最终消息写入时组合，AI 原稿单独保存在回合中。TTS 读取同一份最终消息。已有战斗及带已确认战斗结果的后续调用暂缓 `dm_delta`，检查完成后发布最终文字。
- 守卫最多调用一次模型，仅允许改写文字，不提供工具。必须清除全部已检测矛盾才能采用改写。请求失败、异常、空回复、过短回复、仍有矛盾时丢弃原稿，使用引擎结论；没有可确认事件时使用当前遭遇状态或中性提示。
- 叙事变体也检查已存储的工具事实，不能通过重述绕过结论；不会重执行规则工具。桌面安全边界继续约束叙事与结论。

## 验证

以下是上一轮的真实验收：Codex CLI 订阅 **0.162.1 / gpt-6-astra**。使用隔离数据库、真实 MCP 与规则工具；骰子固定以便核对结果，不代表自然随机样本。没有修改正式战役或服务器配置。术语修复后的验收另存记录，模型以当次运行实际解析值为准。

| 场景 | 引擎结论及核对 |
| --- | --- |
| 未命中 | 一次攻击未命中，敌人生命值不变 |
| 命中后存活 | 7 点伤害，敌人仍存活 |
| 致命攻击 | 7 点伤害，明确死亡 |
| 非致命攻击 | 7 点伤害、击倒，未判定死亡 |
| 两名同类敌人 | 指定第二名哥布林，工具目标 ID、结论和叙事对应同一目标 |
| 魔法飞弹 | 一次施法、9 点伤害、仅消耗一个一环法术位 |

另将“长剑刺入哥布林的胸膛”注入实际未命中的回合，真实 Codex 用一次文字调用纠正；未新增骰子，敌人生命值不变。六段真实叙事由实施代理逐条对照引擎事实阅读，未发现结果矛盾；这不是独立人工审校或生产召回率统计。

[运行原文与结构化结论](chinese-combat-runtime.json)保留实际输出。前四场与后两场分批执行；双敌人的初始测试场景超过单个一级角色的难度预算，随后加入第二名临时队员，保留引擎原有难度检查后通过。未修改基线 golden 文件。

受控模型/语音传输回归覆盖：成功纠正、纠正后仍错误、空回复、HTTP 不可用。每种情况都核对最终消息、流式事件、TTS 输入、骰子次数、生命值与一次纠正预算。纯策略测试另覆盖异常与短回复；事实测试覆盖编号目标、混合命中、多重攻击、零伤害重击、反制消耗、预览、机会攻击与行动者归属。

完整回归 **518/518 脚本套件通过**。末轮行动者 ID/施法表述修正后，受影响套件另行复验；TypeScript 和 lint 结果见[检查记录](chinese-combat-checks.json)。生产构建未在本任务中重新验收，先前的构建阻塞继续单独跟踪。

## 剩余限制

自由叙事守卫仍是保守的语言匹配，不能保证识别全部隐喻、代词、回顾或同一目标的多次攻击归属。关键结论由引擎确定，但不能把“未检测出矛盾”当作对所有文学描写的语义证明。可确认的伤害、状态和资源字段才会进入事实；更多工具、条件和内容包的结果适配仍需补充。

上一轮记录中 AI 描写保留了 `Goblin`；本轮通过共享术语、敌人显示名和生成规则修复，不改写旧记录。详见[本轮修复与验收](chinese-terminology-repairs.md)。TTS 验证的是最终安全文本进入现有语音路径；**本地中文 TTS 仍未配置，发音与真实音频播放未验收**。

复现：`node scripts/accept-chinese-combat.mjs /absolute/output.json`，可用 `ACCEPT_CASES=miss,spell-slot` 选择场景。该脚本使用当前 Codex 订阅，会实际调用模型；普通回归不调用真实模型。
