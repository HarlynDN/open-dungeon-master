# 中文检定说明与电影模式界面

本轮增加与语言无关的检定显示数据（保留跳跃落地的难度 10 和已公开的擒抱挣脱难度），并本地化 CinematicParts 自有界面。群体检定、怪物对抗检定、擒抱／推撞／挣脱、躲藏、搜索、跳跃落地、解除／反制／挣脱法术现在明确传递用途、技能／属性及名字身份。普通 request_roll 的技能／属性／豁免也保留元数据，实体骰等待和提交沿用上一轮的持久化接口。玩家取名 Goblin 或名字含逗号、vs、下划线时保留原样；敌人目录名显示为“哥布林”。

## 规则及接口

RollPresentation 增加 check 类型和有限的用途上下文；未知类型、损坏字段和额外私有字段仍被拒绝或移除。每个用途由独立消息模板渲染，新增语言沿现有注册表和完整目录扩展。接口没有新增工具参数，也没有改变技能选择、骰子表达式、自动失败、资源消耗、群体至少半数成功、对抗平局、擒抱距离／行动／状态或豁免结算。

rollCharacterCheck 默认保留调用者的自定义说明，已核对的原生调用者显式提供用途。rollCharacterSave 接受原字符串或带原英文 detail 的显示对象；Diehard 等原有规则检查仍读取原英文 detail。cast_at_player、区域对玩家的豁免及伤害后的专注豁免已接入明确来源／专注模板。其他敌人／玩家的强制豁免和部分特殊骰子路径仍待接入；原生功能名称未全面翻译。自定义场景标题、功能名、理由及不认识的正文保持原文。

电影模式的回合、先攻名、队伍生命值／职业、任务、纪事、输入模式、发送、骰子提示和无障碍标签使用语言目录。人名、任务正文、既有叙事／玩家台词／系统消息及外部传入 placeholder 保留原样；通用玩家日志模板另有待完成范围。输入模式值、回调和骰子数据不变。英语骰子提示原来把所有失败写为 Miss，中文按攻击／其他检定分别显示“未命中”／“失败”；英文保持原输出。盲骰纪事在两种语言中显示隐藏提示，替代没有结果的空算式，这是单独验证的显示修正。
