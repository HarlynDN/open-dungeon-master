# 中文掷骰显示：攻击、范围伤害与死亡状态

这轮为引擎生成的掷骰说明增加与语言无关的显示数据。中文卡片现在能区分敌人“哥布林”和取名 Goblin 的玩家，显示范围伤害的目标及伤害类型、死亡豁免的常见修正、稳定后的恢复等待，以及实体骰标记。攻击与伤害两个等待阶段的说明行也支持语言切换。

## 接口与兼容

`rolls` 和 `pending_rolls` 增加可空的 `presentation_json`，公开对象增加可选 `presentation`。旧行没有该字段，仍使用原说明；不回填或翻译旧历史。未知、损坏或未来类型的元数据回退到原说明，额外字段不会进入显示投影。新增数据没有结果值、实体 ID 或私有结算上下文的结构字段，名字及自定义文字保持字面值。

生产者通过 `againstRoll`／`areaRoll` 同时保留原英文 detail 和目标身份类型。角色、宠物、物品及其他专名保留；目录敌人使用已有显示译名。目标名单作为数组传递，不通过逗号或 `vs` 拆名字。所有原有使用 rollAgainst／rollOn 的引擎目标说明路径均已接入；其中虹光喷射显式区分玩家与敌人，实体骰等待和提交保留相同的显示数据。模型工具名、字段、骰子表达式、难度、结果、消耗和伤害应用逻辑不变，原英文 detail 的长度上限也不变。

范围目标沿用原有可见性及塑形法术过滤。隐藏施法者显示“未现身者”，不额外推定为施法职业；隐藏目标和施法者的原名不会写入新增显示数据。原有 attacker 字段的 ID 语义仍然保留。盲骰继续隐藏难度、结果和骰子细节；新数据只提供本来就可公开的说明。

旧记录没有目标身份时，不能从攻击者类型推断对方是否是怪物，因此保留原目标名。玩家名中出现 Goblin、逗号、vs 或下划线也不会被替换。自由填写的理由、自定义状态来源和不认识的正文保持原文；中文说明适配器仅处理已核对的引擎句式和目录词。

## 资料与英语回归

新增 46 个双语消息键进入 combatRoll 内容资源，首页通用 UI 资源没有增加。包括 12 个常见攻击名称、7 种虹光颜色、伤害／坠落框架、死亡豁免与常见修正说明。源文审查记录为 [roll-presentation-translations.json](roll-presentation-translations.json)，回归校验源文和目录指纹。红／绿／蓝是颜色；原有种族选择中的同名英文词指红龙／绿龙／蓝龙，属于明确的语境差别。

改动中文适配器和界面前，冻结 25 份真实 RollCard 英文组件渲染；原英文渲染函数没有变化，早期类型和工厂新增属于附加接口。压缩文件 2257 字节，原始字节 SHA-256 为 e6e7532b8b39e5d0fd8219ebe19b8a3b66f1664174d259b9b3ac35b1bc34de51。此前 19 份压缩英语基线和 10716 个双语资源值保持原样。真实等待攻击／伤害卡片还对比了有无新元数据的英文渲染，并保持理由字符串原输出。
