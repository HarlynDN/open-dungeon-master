# 中文豁免来源与用途

本轮为 47 处已有豁免说明补充与语言无关的来源、用途和名字身份，并为三个功能豁免调用显式传递上下文。包括法术初次／后续豁免、状态结束、攻击附带效果、受伤后摆脱法术、专注、持续区域、地震裂隙、虹彩喷射紫色光线及坐骑落地。这里的完成范围是共享豁免接口的已有记录；没有为原本不记录的敌人豁免新增公开记录。

原英文 detail 保留原样，继续供规则与工具结果使用。新增展示数据经过现有持久化和恢复解析；没有修改能力选择、豁免难度、优势／劣势、伤害、资源消耗、自动失败、状态释放或传奇抗性。本轮涉及的敌人记录继续只有 DM 可见，秘密骰仍隐藏数值、难度及掷骰明细。玩家、NPC 等专有名词和显式自定义能力／反应名字保留原文，包括恰好叫 Fireball 的自创能力；目录敌人名显示为哥布林。

新增 17 个双语键：11 个用途模板及六个来源名称／描述。五个原生能力译名（不屈狂暴、不屈、亡灵韧性、龙族威仪、自然庇护）加入语境术语表；颤震掌、法师杀手和法术／状态名沿用既有译文。接口支持未来语言通过目录渲染，业务调用传用途和原名，不传固定中文。其他原生能力／反应的名称目录尚待扩展。

从 git show 3db1642e 的源码采集 23 份实际 RollCard 英文渲染及 60 处豁免调用原参数，分别压缩保存在 save-caption-goldens.json.gz 和 save-caption-contracts.json.gz。未压缩 SHA-256 分别为 24bb9373e2d013d4cfc15ba54707a9c926da522d47a7f57e79bc86a68f74f7f2 和 3078e220f595352618e027c56e978e9ae54943143d141840dd5ad72bc0f03f89。当前渲染逐字一致，调用去掉新增展示数据后仍逐项相同，包括原英文说明、DC、规则标志和有无记录的决定。已有全部 10902 个双语资源值及 21 份压缩基线保持原样。

旧 check/cinematic 与 roll-caption 审查记录只同步受影响源码的指纹，同时记录原指纹和核对内容。没有重写任何已有英文基线，也没有把新增范围视为旧审查已覆盖。新增测试初版误把按时间正序返回的 recent 窗口首项当作最新记录，修正为末项；法术／攻击断言也改用项目已确定的术语。引擎行为和译文未为迎合夹具假设而修改。
