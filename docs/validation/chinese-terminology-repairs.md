## 名称接口

`referencePresentation(kind, entry, locale)` 同时返回实体 ID、原始名称、当前语言显示名和允许别名。遭遇敌人列表提供显示名与原名，先攻顺序按敌人 ID 显示名称；角色的自定义名字保持原样。生成规则要求普通目录名称使用显示名，并提供已知怪物的术语映射，覆盖同一次模型调用内新建遭遇后收到英文工具结果的情况。

`Goblin` 的标准显示名是“地精”，`Goblin 2` 为“地精 2”；“哥布林”仍是允许的输入别名。自定义名称如 `Goblin King Gruk` 不通过字符串替换翻译。工具名称、参数字段、原始目录名称、敌人 ID、数据库记录及历史消息不改写。显示和中文守卫读取同一份别名；同类敌人及混合挥击的模糊叙事继续采用原有保守规则，不能宣称已实现所有逐事件语义归属检查。

## 术语规范与检查

`src/lib/i18n/glossary.zh-CN.ts` 保存 225 条原始编辑规范，包括规则、语言、怪物和 UI 标签。条目有稳定 ID、英文来源、标准译名、适用消息键及可选输入别名、禁用译法。`TERMINOLOGY` 按应用 locale 注册；扩展语言时显式补充对应规范和已有战斗渲染器。

本轮采用：Factions＝势力、Alignment＝阵营、AC＝护甲等级、Goblin＝地精、Bugbear＝熊地精、Hobgoblin＝大地精、Acrobatics＝特技、Survival＝求生、Warlock＝邪术师。统一保存更改、新建角色、起始财富、电子骰、背景故事等同义标签；普通叙事中的“生存”不全局替换为技能“求生”。这些是项目的编辑选择，不宣称是官方译本，也未复制商业中文版规则书。

## 战斗文案的事实边界

- 使用“获得 N 点治疗”，表达治疗量，不保证等于生命值净增量。
- 编号敌人与后续中文之间留空格，数值按现有 UI 使用阿拉伯数字，如“消耗了 1 个 1 环法术位”。
- 只有明确击昏或 unconscious 状态才写“倒地失去意识，仍然活着”；仅倒下或当前生命值为 0 的保守回退不推断意识状态。
- 真实施法效果工具确认成功时写“施放了某法术”，不保证目标受到了效果。只完成施法资源处理时写“某法术的效果尚待确认”。
- 反制、行动无法完成和结果未确定分别呈现；反制已消耗的法术位仍保留，不声称退款。玩家文案不暴露“规则引擎未确认”“施法已登记”等措辞。
